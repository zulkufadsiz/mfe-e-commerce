# MFE E-Commerce

## Overview
Micro Frontend E-Commerce application built for scalability and modularity.

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation
```bash
npm install
```

### Running the Application
```bash
npm start
```

## Project Structure
```
src/
├── components/
├── pages/
├── services/
└── utils/
```

## Available Scripts
- `npm start` - Start development server
- `npm build` - Build for production
- `npm test` - Run tests
